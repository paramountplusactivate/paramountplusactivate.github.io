TROUBLESHOOTING

Paramount+ Activation Problems

Try these basic checks if your device does not activate properly.

Activation Code Is Not Working

Check that you are using the current code displayed on your device. If the code has expired, restart the activation process and check for a new code.

Paramount+ App Is Not Loading

Check your internet connection, restart the streaming device, and make sure the Paramount+ application is updated.

Sign-In Is Not Working

Verify your account information and make sure you are using the correct Paramount+ account.

Device Compatibility Problem

Check whether your device model and operating system support the Paramount+ application.
