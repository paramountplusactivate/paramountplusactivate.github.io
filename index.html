How to Activate Paramount+

Use the steps below to connect Paramount+ with your supported streaming device. Keep your account details ready before starting the setup.

01

Open Paramount+

Launch the Paramount+ app on your smart TV, streaming player, or supported gaming console.

02

Choose Sign In

Select the sign-in option and follow the instructions displayed by the Paramount+ application.

03

Enter the Activation Code

If an activation code appears on your screen, use the code exactly as displayed during the device setup.

04

Finish Device Setup

After your account is connected, return to the Paramount+ app and wait for the home screen to load.

TROUBLESHOOTING

Paramount+ Activation Help

Activation may not complete if the code has expired, the app needs an update, or the device has a connection problem. Try these basic checks before starting again.

Activation code expired

Close the activation screen and request a new code from the Paramount+ app.

Code is not accepted

Check that you are entering the current code exactly as it appears on your device.

App is not loading

Restart your device and check that your internet connection is working normally.

Sign-in is unsuccessful

Verify your account details and try signing in again.
